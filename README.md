# learning-coach
# 学能诊断教练

> 个性化问题诊断，真正提升解题能力

基于北京大学心理学博士两年、20+ 名真实学生深度干预案例设计的 AI 学习障碍诊断系统。

---

## 产品理念

传统辅导的问题：老师讲解解题步骤，学生听懂了，考试还是不会。

根源在于：学生记住的是「这道题怎么做」，而不是「遇到这类题我该怎么想」。

**学能诊断教练的不同之处：**
- **不讲题，只扫障碍** — 找到学生思维链上的断点，针对性清除
- **不给步骤，只给工具** — 帮学生建立可迁移的思维框架
- **每次诊断后输出** — 完整执行方案 + 薄弱知识点清单 + 复习任务

---

## 核心方法论

基于 8 名真实学生两年干预案例，提炼出 5 大类、14 种学习卡点：

| 类别 | 卡点 | 频率 |
|------|------|------|
| A 知识输入 | A1 知识掌握表层 / A2 记忆散碎 / A3 混淆概念 | ★★～★★★★★ |
| B 知识检索 | B1 凭直觉判断 / B2 公式无法反向检索 / B3 无法转化所求 / B4 条件不敏感 / B5 空间想象力弱 / B6 条件翻译不到位 | ★★～★★★★★ |
| C 执行计算 | C1 计算不优化 / C2 没想清楚先动笔 / C3 粗心遗漏 | ★★★ |
| D 学习管理 | D1 思维外显不足 / D2 检验标准模糊 | ★ |
| E 考试执行 | E1 学考分离 | ★ |

---

## 技术架构

```
学生输入错题
      ↓
Claude API（系统提示词 = 学能诊断知识库 v1.3）
      ↓
苏格拉底式多轮对话引导
      ↓
输出：卡点总结 + 执行方案 + 复习任务
```

- **前端**：原生 HTML/CSS/JS，移动端适配
- **后端**：Python Vercel Serverless Function
- **AI**：Claude claude-sonnet-4-6（Anthropic API）
- **部署**：Vercel

---

## 本地运行

```bash
# 安装依赖
pip install anthropic

# 设置 API Key
export ANTHROPIC_API_KEY=your_key_here

# 启动本地服务（仅前端预览）
cd learning-coach
python3 -m http.server 7790
# 访问 http://localhost:7790
```

> 注意：本地运行时 `/api/chat` 接口不可用，需部署到 Vercel 后才能使用完整功能。

---

## 部署到 Vercel

1. Fork 本仓库
2. 在 [Vercel](https://vercel.com) 导入项目
3. 设置环境变量：`ANTHROPIC_API_KEY = your_key`
4. 部署完成，访问生成的域名

---

## 项目背景

本项目由北京大学心理学博士生陈楚怡设计，基于以下研究发现：

- 传统「讲题式」辅导的核心缺陷是「步骤传递」而非「思维建构」
- 高中生学习障碍存在可分类、可诊断、可干预的规律性模式
- AI 在「路障清除」模式下，可以有效替代部分高质量一对一辅导功能
